# V2.1.0 角色权限与商家租户隔离

## 仅保留三种角色

| role | 中文角色 | 权限边界 |
|---|---|---|
| `admin` | 管理员 | 全站管理：用户、商家、订单、任务分配、视频、审核记录和统计 |
| `producer` | 拍摄剪辑 | 只访问管理员分配给自己的制作任务；接单后上传视频、提交修改版本 |
| `merchant` | 商家 | 只访问自己发布的订单、需求、项目资料、发布任务和这些任务的全部当前交付视频；审核通过或退回修改 |

旧角色迁移：`super_admin` → `admin`；`manager` / `editor` / `viewer` 和未知旧角色 → `producer`（最小权限）；`merchant` 保持不变。迁移不删除用户记录。

## 商家隔离

- 商家身份必须通过 `MerchantAccount` 关联唯一商家档案。
- 订单使用 `BusinessOrder.merchant_id`；发布任务使用 `PublishTask.merchant_id` 和 `order_id`；视频通过 `PublishVideo.task_id` 关联任务。
- 商家列表、详情、任务、视频流、审核和发布登记均在服务端按当前登录用户的 merchant_id 校验；仅 `approved` 状态的商家可以访问，`rejected` / `suspended` 账号保持阻断。
- 视频流接口同时校验 task_id 与 link_id，不能只依赖前端隐藏或难猜 ID。
- 商家最终点击“确认已发布”后，原始视频文件按配置清理；视频元数据和审核历史保留，清理后的文件不能再通过任何视频流接口访问。
- 项目素材下载同样校验所属商家与关联订单/需求。
- 商家不能通过请求参数自行提交或覆盖 merchant_id。

## 拍摄剪辑隔离

- 拍摄剪辑列表只查询 `assigned_user_id = current_user.id` 的任务。
- 单个任务详情、审核历史、视频流、上传、替换接口均再次校验任务分配人。
- 必须先接单，才允许上传制作视频。
- 商家退回的视频，拍摄剪辑只能通过对应视频的“提交新版”接口替换；旧版本保留审核历史。
- 拍摄剪辑不能访问订单台账、商家列表、项目报价、财务、系统用户管理或通用素材库。

## 微信注册安全

- 公开注册仅开放 `merchant` / `producer`；绝不允许客户端创建 `admin`。
- 邮箱/短信 OTP 的 `register` 用途和旧 `/auth/register` 入口返回 410；密码登录仅保留给管理员和已有兼容账号。
- 微信 OAuth `state` 使用 HMAC/JWT 签名、随机 nonce、数据库单次消费和 5 分钟有效期。
- 同一微信 openid 只能绑定一个用户；已存在身份再次选择其他角色时保留原角色。
- 微信授权启动接口按 IP 做短时频率限制；每个账号只允许一个微信身份绑定。
- AppSecret 只保存在后端环境变量，不返回前端。

## 仍建议后续增强

- 管理员 TOTP/WebAuthn MFA。
- WAF/反向代理级别的分布式限流与异常设备检测（当前应用限流为单进程内存级）。
- 审计日志保留周期、媒体下载审计和对象存储签名 URL。
- 大文件视频转码/OSS 迁移与恶意文件扫描。
