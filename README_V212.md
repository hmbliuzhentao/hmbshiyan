# 黑曼波工作台 V2.1.2（总后台 + 视频工作台 + 交付中心）

相对于 V2.1.1：

- 根据最新流程手绘图整理为三个业务域名：`heimanbo.com` 总后台、`video.heimanbo.com` 视频工作台、`deliver.heimanbo.com` 交付中心；不再新建独立商家后台。
- 管理员总览新增商家数、账号数、待分配、待审核、退回修改统计，以及订单/任务/商家/账号/视频/日志六个快速入口。
- 订单入口新增页内“订单台账与收款”和“商家申请与需求”切换；侧栏保持简洁。
- 新增操作记录菜单，复用管理员专用 `/api/system/audit-logs`。
- 商家端保留自主微信注册和管理员后台建号，交付审核与退回意见仍由原来的商家关联订单接口保护。
- 增加多域名的后端角色权限映射和示例 Caddy 站点块。
- 保留现有 test-v2 测试入口、Logo、PostgreSQL/视频数据卷名和 Docker Compose，不改变数据库表结构。

**状态：本地源代码修改。** 新域名须用户配置 DNS/HTTPS 与微信 OAuth 认证，不能仅靠部署 ZIP 自动生效。`frontend`、`backend` 镜像均须从对应源码分别构建、验证再切换。不要使用曾经打错包的 `frontend:v2.1.0` 镜像。

部署顺序：核对 GitHub 新分支已包含完整 V2.1.2 源码 → ACR backend/frontend 构建不同新标签 → 检查前端镜像 `CMD ["node","server.js"]` → 仅更新应用容器 → 按需配置 Caddy 与 DNS → 三角色功能与数据隔离验收。
