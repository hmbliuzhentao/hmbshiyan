# 微信开放平台网站应用申请材料清单（有限公司）

官方入口：https://open.weixin.qq.com/

1. 使用企业长期持有的邮箱注册微信开放平台账号。
2. 选择企业主体，按营业执照填写全称、统一社会信用代码、管理员姓名、联系方式，按平台要求完成身份验证和开发者资质认证。
3. 开发者资质认证通过后，在「管理中心→网站应用→创建网站应用」申请微信登录。
4. 网站应用名称建议：「黑曼波工作台」。简介示例：「面向商家与短视频制作团队的订单协作与视频交付平台，提供订单发布、任务分配、视频制作、审核与交付等服务。」官网优先提供可访问且有企业信息、隐私政策和联系渠道的正式站点，不要只有登录页。
5. 授权回调域需要和网站真实回调地址域名严格一致（只能填写域名，不带 https:// 或路径）。当前测试环境配置为 `test-v2.heimanbo.com`，回调 URI 为 `https://test-v2.heimanbo.com/api/auth/wechat/callback`。若最终选 `auth.heimanbo.com`，应先配置 DNS/HTTPS 并调整代码环境变量，然后再申请该回调域。
6. 准备公司营业执照、企业公章、管理员身份证明及微信要求的《网站信息登记表》；实际字段、资质审核费用、官网及备案材料以平台页面为准。
7. 美国服务器通常不需要为服务器自身办理中国大陆 ICP 备案，但微信网站应用审核可能要求网站备案/许可证信息；这两项不是一回事。若审核页要求备案号，不要编造；按平台规则咨询审核或选择合规方案。
8. 审核成功后，获得 AppID 和 AppSecret，**不要把 AppSecret 发到聊天**，只在服务器 `.env` 等秘密存储中配置。
9. 接入后必须验证 OAuth state 防重放、微信绑定唯一性、角色权限和不同商家数据隔离；微信授权只减少密码爆破风险，仍需风控限速。
