# 黑曼波工作台 V2.0.2 Dev4

本版本在 V2.0 Dev3 基础上接入可操作的业务模块。保留原始品牌 Logo、
V1.5 旧版页面、原有 Docker 卷和 Caddy 入口，不对数据库执行删除操作。

## 本次接入的业务功能
- 内部管理：订单台账、商家管理、员工账号、真实订单统计
- 制作中心：商家订单需求与进度、视频任务交付和审核
- 视频素材库：上传、搜索、预览及按权限删除
- 产品、脚本、分镜、提示词等资料：列表、搜索、新建、编辑、归档和删除
- 商家端：发布制作需求、查看自身订单、审核交付视频
- 商家自助注册的管理员审核：待审核、通过、要求补充资料、拒绝
- 测试域名根据已登录角色自动进入对应面板，刷新后也能恢复

## 自动测试
GitHub Actions 工作流 `.github/workflows/v20-ci.yml` 执行前端 TypeScript 检查、
Next.js 构建及后端认证、商家租户隔离、订单任务测试。部署前确认全部通过。

## 镜像版本
阿里云 ACR 从 `v2.0-deploy` 分支构建：
- Backend: `/full-code-v20/backend`，`backend:v2.0.2`
- Frontend: `/full-code-v20/frontend`，`frontend:v2.0.2`

`compose.yaml` 已引用新标签，必须先完成两项构建再更新服务器。
现有 ECS 资源较小，沿用 Dev3 的内存限制。复用现有 Caddy，不启动第二个实例。
